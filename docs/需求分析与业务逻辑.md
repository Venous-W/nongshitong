## 一、客户端（销售）

### 1.1 查询页

**筛选框架：**
- 顶部搜索框：农药名 / 有效成分 / 防治对象模糊搜索
- 四步按钮筛选：一级分类 → 二级分类 → 作物/场景 → 防治对象；每步多选、OR 逻辑
- 顶部已选条件区（可单个移除）+ 面包屑导航 + 分页
- 结果中已选的作物/防治对象标签高亮

**筛选联动规则：**
- 二级分类展示所有已选一级的子类合集（多选一级时取并集）
- 作物/场景、防治对象选项均为动态加载，只显示当前条件下实际有产品覆盖的选项
- 防治对象按已选一级分类的类型过滤（除草→杂草、杀虫→虫害等，多选一级时取类型并集）
- 关键规则：每步均为动态查询结果，不会出现"选完没有产品"的死路

**产品卡片字段：**

| 公共可见                                          | 登录后追加                                              |
|---------------------------------------------------|---------------------------------------------------------|
| 产品名、分类路径                                  | 规格列表（每规格：规格名、单价=10件以下价、10件以上价） |
| 适用作物标签、防治对象标签                        | 每规格提成（元/件，各规格不同）                         |
| 产品图片（多张缩略图，点击放大，可右键复制/保存） | 当前库存（产品级共用）                                  |
| 角标标签（本月推荐/最近热销等，左上/右上角）      | 老板备注（醒目样式）                                    |
|                                                   | 下单按钮                                                |

**排序规则：** 带角标标签的产品默认排在前面，其余按常规排序。

**产品详情弹窗：** 分类路径、产品图片（点击放大）、用量、适用作物、防治对象、使用方式、注意事项 + 登录后的价格/提成/库存/老板备注。

### 1.2 下单流程

| 步骤     | 确定需求                                                                                                                           |
|----------|------------------------------------------------------------------------------------------------------------------------------------|
| 入口     | 登录后产品卡片/详情弹窗的"下单"按钮                                                                                                |
| 表单     | 选择规格（展示该规格阶梯价与提成）→ 输入数量 → **系统按阶梯自动算建议实收金额（可修改）** → 客户（可从客户档案选或新填）→ 收货地址 |
| 价格逻辑 | 数量 ≥ 阈值（默认10，全局可配）用"10件以上"价，否则用"10件以下"价；**一件的价格 = 10件以下价**                                     |
| 提成逻辑 | 该规格提成 × 数量（管理端事后可改）                                                                                                |
| 提交     | 二次确认弹窗 → 提交直接生效 → **库存自动扣减** → 生成订单与发货信息                                                                |
| 库存不足 | 数量超过库存时禁止提交并提示                                                                                                       |
| 取消     | 未发货订单：销售本人可取消、管理端也可取消；**取消后库存自动回退、提成作废**                                                       |

**发货信息格式**（一项一行 "项: 内容"，支持一键复制 / 打印面单）：
```
客户姓名: 张三
手机号: 13812345678
收货地址: ××省××市××县××镇××村
产品规格: 41%草甘膦异丙胺盐 - 25公斤 × 2
实收金额: 680元
订单编号: SO20260812001
下单人: 李四（销售）
```

### 1.3 个人页面

| 模块             | 确定需求                                                                                                                                                                                    |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ① 本月汇总小卡片 | 我的本月销售额、本月提成、订单数（按当前提成周期统计）                                                                                                                                      |
| ② 我的发货记录   | 分页列表：订单编号、下单时间、产品规格×数量、客户姓名/手机/地址、实收金额、我的提成、发货状态（未发货/已发货/已签收/退回/已取消）、快递单号；操作：复制发货信息、打印面单、取消（仅未发货） |
| ③ 客户档案       | 历史客户列表（姓名/手机/地址），下单时可直接选用，支持新增/编辑                                                                                                                             |
| ④ 个人备注       | 销售自己的笔记，增删改                                                                                                                                                                      |
| ⑤ 我的销售语录   | 个人维护，增删改 + 一键复制                                                                                                                                                                 |
| ⑥ 公共语录       | 所有销售上传的优秀语录，全员可见可复制；**上传者本人 + 管理员**可修改/删除；含"我上传的"筛选                                                                                                |
| ⑦ 修改密码       | 自助修改                                                                                                                                                                                    |

## 二、管理端（老板）

### 2.1 首页（数据看板 + 提成统计）

- **提成周期设置**：自然月（1号-月底）或自定义起始日（如每月15号-次月14号）
- 默认按当前提成周期统计，**支持自定义时间范围查历史**
- 概览卡片：销售总额（实收）、订单数、提成总额、待发货数
- 每人销售情况：排行/明细表（每人订单数、销售额、提成）
- 产品热销 TOP 榜
- 库存预警（低于阈值高亮提醒）

### 2.2 订单/发货管理

| 项        | 确定需求                                                                                                                       |
|-----------|--------------------------------------------------------------------------------------------------------------------------------|
| 列表字段  | 订单编号、下单销售、客户姓名/手机、地址、产品规格×数量、实收金额、提成、状态、快递单号、下单时间                               |
| 筛选/搜索 | 按销售、状态、产品、时间范围筛选；按单号/客户手机/姓名搜索                                                                     |
| 操作      | ① 改状态：未发货→已发货（必填快递单号）→已签收 / 退回；② 修改提成；③ 取消未发货订单（库存回退、提成作废）；④ 复制/打印发货信息 |

### 2.3 产品管理

- 列表：缩略图、名称、分类、规格数、库存、标签、上架状态；操作：新增/编辑/删除/上下架
- 编辑弹窗：分类联动（一级+二级）、名称、产品图片多张上传、用量、使用方式、注意事项、适用作物多选、防治对象多选（按类型分组）、老板备注、角标标签、库存数量（产品级）、规格表（每行：规格名 / 提成 / 10件以下价 / 10件以上价，可增删行）、上架状态
- 删除保护：已被订单引用的产品不可删除，只能下架
- 标签管理：可新增标签名（如"本月推荐""最近热销"）并打在产品上

### 2.4 分类管理
树形一级→二级；一级分类设"关联防治类型"（除草→杂草、杀虫→虫害等）；增删改；有产品关联不可删。

### 2.5 作物管理
平铺列表增删改；有产品关联不可删。

### 2.6 防治对象管理
平铺列表，类型标签（杂草/虫害/病害/调节剂），按类型筛选；有产品关联不可删。

### 2.7 用户管理
- 新增账号：姓名、手机号（作账号）、初始密码、角色（销售/管理员）
- 启用/禁用、重置密码；有订单记录的用户不可删除（只能禁用）
- 无独立"语录管理"模块（语录由销售个人/公共自维护，管理员可在公共语录处改删）

### 2.8 系统设置
提成周期、阶梯价阈值（默认10件）、库存预警阈值。

## 三、数据模型

- **用户**：姓名 / 手机号(账号) / 密码 / 角色 / 启用状态
- **分类**：树形（一级→二级），一级含 target_type（关联防治类型）
- **作物**：平铺，含农作物与非农作物场景
- **防治对象**：平铺，含类型（杂草/虫害/病害/调节剂）
- **产品**：基本信息 + 图片(多张) + 老板备注 + 标签 + 库存(产品级) + 上架状态 + 关联(分类/作物/防治对象)
- **规格**（属于产品）：规格名 / 提成 / 10件以下价 / 10件以上价
- **订单**：销售 / 规格 / 数量 / 单价 / 实收金额 / 提成 / 客户信息 / 地址 / 状态 / 快递单号 / 时间
- **客户档案**（属于销售）：姓名 / 手机 / 地址
- **备注**（属于销售）：内容 / 时间
- **语录**：内容 / 作者 / 是否公共 / 时间

## 五、"作物"的统一定义

"作物"含义做扩展处理：**作物 = 所有可以作为施药场景的载体**，包括：
- 农作物：玉米、小麦、花生、大豆、高粱、水稻、棉花……
- 非农作物场景：果园、茶园、橡胶园、田埂、路边、铁路沿线、荒山荒地、城市园林……

灭生性除草剂的适用范围（果园/田埂/路边等）与农作物一样，统一作为 `crops` 表中的一条记录，不做特殊区分；查询流程对所有二级分类统一走"选作物"步骤，无需跳过逻辑。

**好处：**
- 代码逻辑统一，无需对灭生性除草剂做特判
- 管理员可自由新增"作物/场景"，系统自动出现在按钮中
- 灭生性除草剂查询时选"果园"或"田埂"等，逻辑与选"花生"完全一致

## 七、实现约定

1. 所有接口统一返回 JSON，格式：`{"code": 0, "data": ..., "msg": "ok"}`；错误时 `code` 非0，`msg` 说明原因
2. 删除保护：有产品关联的作物/防治对象/分类不可删除（返回错误提示）；已被订单引用的产品不可删除，只能下架
3. 产品 `is_active=0` 时查询页不显示，管理页仍可见
4. 种子数据使用 INSERT OR IGNORE，重复启动不重复写入
5. 所有中文内容统一使用 UTF-8 编码
