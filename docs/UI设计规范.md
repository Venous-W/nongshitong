# UI 设计规范 — 农科潮牌（AgriTech Bold）

风格基调：田间自然 × 潮流撞色。纸米白暖底 + 森林绿/荧光青柠/落日橙撞色，大圆角杂志式排版，大号无衬线粗数字。撞色只做点缀，不淹没高密度数据。

## 一、设计 Token（CSS 变量）

```css
:root {
  /* 主色 */
  --green-900: #0B3D2E;   /* 深墨绿：文字、深色块 */
  --green-700: #0E7A4E;   /* 森林绿：主色、主按钮 */
  --green-500: #22B573;   /* 亮绿：hover、辅助 */
  --lime-300:  #C9F33A;   /* 荧光青柠：角标、高亮、渐变端点 */
  --orange-500: #FF6B35;  /* 落日橙：价格、提成、CTA、促销 */
  --orange-200: #FFC7AE;  /* 浅橙：hover 底 */

  /* 中性 */
  --paper:     #FAF6EF;   /* 纸米白：页面背景 */
  --surface:   #FFFFFF;   /* 卡片面 */
  --ink:       #123F2E;   /* 墨绿近黑：正文标题 */
  --ink-weak:  #5C746B;   /* 次级文字 */
  --ink-faint: #8FA39A;   /* 弱文字/占位 */
  --line:      #E7E0D2;   /* 边框 */
  --line-strong:#D8CFBB;

  /* 状态色 */
  --danger:  #E5484D;     /* 库存不足、删除、取消 */
  --success: #18A058;     /* 成功、已签收 */
  --warn:    #FFB020;     /* 待发货提醒 */

  /* 防治对象分色（用于标签系统） */
  --tag-weed:    #FF6B35; /* 杂草-橙 */
  --tag-pest:    #E5484D; /* 虫害-红 */
  --tag-disease: #2F7DE1; /* 病害-蓝 */
  --tag-reg:     #8B5CF6; /* 调节-紫 */

  /* 形状与阴影 */
  --radius-sm: 8px;
  --radius-md: 14px;
  --radius-lg: 20px;
  --radius-pill: 999px;
  --shadow-sm: 0 1px 3px rgba(18,63,46,.08);
  --shadow-md: 0 6px 20px rgba(18,63,46,.10);
  --shadow-lg: 0 14px 40px rgba(18,63,46,.14);

  /* 字体 */
  --font: "PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui,sans-serif;
  --font-num: "DIN Alternate","Bahnschrift",var(--font); /* 数字等宽感，sales 用 tabular-nums */
}
```

## 二、排版原则

- 标题/产品名/价格/统计数字用**大字号粗字重**；表格和表单用常规字号，保证数据密度。
- 数字一律 `font-variant-numeric: tabular-nums`，对齐不跳动。
- 层级：主标题 20–24px / 卡片标题 16–18px / 正文 14px / 辅助 12px。
- 行高：正文 1.6，标题 1.3。

## 三、组件风格

| 组件      | 规范                                                                                                                                                      |
|-----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| 主按钮    | 森林绿底 `#0E7A4E` 或 绿→青柠渐变 `linear-gradient(135deg,#0E7A4E,#22B573)`，圆角 `--radius-pill`，hover 提亮；关键 CTA（下单、保存）可用落日橙 `#FF6B35` |
| 卡片      | 白底 `--surface` + `--radius-lg` + `--shadow-sm`；hover 升 `--shadow-md`                                                                                  |
| 筛选胶囊  | 圆角 pill，未选=白底描边，选中=青柠底 `#C9F33A` + 墨绿字，可多选                                                                                          |
| 角标/贴纸 | 斜角裁切或圆角方块，橙/青柠撞色，白字或墨绿字，放卡片左上/右上对角，叠在图上                                                                              |
| 玻璃浮层  | `backdrop-filter: blur(12px)` + 半透明白，用于搜索条、筛选区、已选条件条                                                                                  |
| 标签系统  | 防治对象按类型分色（橙/红/蓝/紫，见 token），作物标签用绿系浅底                                                                                           |
| 表格      | 表头浅米底 `#F3ECDE`，斑马纹用 `#FBF8F0`，行 hover 青柠 10% 淡底                                                                                          |
| 弹窗      | 大圆角，标题粗，底部按钮右对齐，主操作渐变大按钮                                                                                                          |
| 顶部横幅  | 深墨绿→森林绿渐变 + 细噪点纹理，大号标题文字                                                                                                              |

## 四、页面级设计要点

### 查询页（重点页）
- 顶部渐变横幅：大标题 + 超大搜索框（白底圆角，放大镜图标）。
- 四步筛选做成胶囊分段条，可横向滚动，选中态青柠填充；多选在胶囊内显示数量（如「玉米 ×3」）。
- 已选条件区：玻璃浮层横条，条件 chips 可单个 ✕ 移除 + 一键清空。
- 产品卡片：大图（白底裁切）+ 大号产品名 + 分色标签 + 角标贴纸叠图；价格/提成（登录后）用橙色大数字。
- 空态/无结果：配大号插画 + 引导文案，不显示生硬表格。

### 详情页
- 左图右文布局（移动端堆叠），图片可放大；价格阶梯用橙色大数字 + 渐变小字标注「10件以上」。

### 下单
- 规格选择卡片、数量步进器、建议实收金额大字展示可改；提交二次确认弹窗用「取消/确认下单」撞色按钮。

### 个人页
- 顶部「本月汇总」三张大卡片（销售额/提成/订单数），数字超大号粗体。
- 语录列表卡片式，复制按钮胶囊。

### 管理端看板
- 概览四卡片，数字巨大；TOP 榜用渐变进度条（绿→青柠）；库存预警行用橙/红高亮 + 警示图标。

### 登录页
- 渐变背景 + 噪点，中央白卡片，Logo 大号字体。

## 五、动效（克制）

- 卡片 hover：轻微上浮 + 阴影加深（150ms ease）。
- 筛选切换：胶囊背景过渡 150ms。
- 数字变化：可加 count-up 动画（看板）。
- 避免：满屏粒子、持续闪烁。

## 六、暗色模式（加分项）

- 底色 `#0F1F18`，卡片 `#162A20`，文字 `#EDF5EF`，青柠/橙保持不变，绿系整体提亮一档。
